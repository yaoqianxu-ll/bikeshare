# 管理端响应式适配设计方案

**日期**: 2026-03-25
**项目**: BikeShare 管理端响应式改造

---

## 1. 需求概述

将 BikeShare 管理后台（bickdemo-admin）进行响应式改造，使手机端也能正常访问和操作核心数据。

## 2. 设计方案

### 核心策略：汉堡菜单模式

**桌面端（≥ 768px）**：保持现有固定 224px 左侧深色侧边栏不变。

**移动端（< 768px）**：
- 顶部显示 56px 高的工具栏（包含 Logo + 汉堡图标按钮）
- 侧边栏默认隐藏，点击汉堡按钮通过 `el-drawer` 抽屉从左侧滑出
- 抽屉宽度 260px，深色背景与桌面侧边栏视觉一致

### 3. CSS 响应式规则

| 元素 | 桌面 (≥768px) | 移动端 (<768px) |
|------|--------------|----------------|
| 统计卡片 | 4列 grid | 1列 grid |
| 图表网格 | 2列 grid | 1列（上下堆叠） |
| 表单网格 | 3列 grid | 1列 |
| 表格 | 固定列 | 横向滚动 |
| 顶部工具栏 | 不显示 | 显示 |

### 4. 组件改造清单

#### AdminLayout.vue
- 新增移动端顶部工具栏（Logo + 汉堡按钮）
- 侧边栏 `<aside>` 改为条件渲染：桌面端保留，移动端使用 `el-drawer`
- 抽屉配置：`direction="ltr"`, `size="260px"`, 背景色 `#0f172a`

#### global.css
- 768px 断点已有样式补充
- 新增 `.mobile-header` 工具栏样式
- 表格容器添加 `overflow-x: auto` 防止列溢出

### 5. 实施文件

| 文件 | 改动内容 |
|------|---------|
| `bickdemo-admin/src/layouts/AdminLayout.vue` | 汉堡菜单 + drawer |
| `bickdemo-admin/src/styles/global.css` | 响应式 CSS 规则 |

### 6. 兼容性

- 框架: Element Plus 2.5 + Vue 3.4
- 断点: 768px（与现有断点一致）
- 不影响现有桌面端布局
