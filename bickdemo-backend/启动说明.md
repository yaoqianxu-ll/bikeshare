# 后端启动说明

## 方式一：使用 IDEA 启动（推荐）

1. 用 IDEA 打开 `bickdemo-backend` 文件夹
2. 找到 `src/main/java/com/example/bickdemo/BickdemoApplication.java`
3. 右键 -> Run 'BickdemoApplication'

## 方式二：使用 Maven 命令

如果已安装 Maven：

```bash
cd bickdemo-backend
mvn spring-boot:run
```

## 方式三：使用 Maven Wrapper

在项目根目录执行：

```bash
# Windows
mvnw.cmd spring-boot:run

# Linux/Mac
./mvnw spring-boot:run
```

## 前提条件

### 1. Java 环境
- JDK 17 或更高版本
- 检查：`java -version`

### 2. MySQL 数据库
- MySQL 8.0 或更高版本
- 执行数据库初始化脚本：

```bash
# 方法 1: 命令行导入
mysql -u root -p < init.sql

# 方法 2: MySQL 客户端执行
mysql -u root -p
source init.sql
```

### 3. 数据库配置

确保 `application.yml` 中的数据库连接信息正确：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/bickdemo?useSSL=false&serverTimezone=UTC&characterEncoding=utf-8&allowPublicKeyRetrieval=true
    username: root          # 修改为你的数据库用户名
    password: 你的密码       # 修改为你的数据库密码
```

## 常见问题

### 1. 端口被占用
错误：`Port 8080 was already in use`

解决：修改 `application.yml` 中的端口号
```yaml
server:
  port: 8081  # 改为其他端口
```

### 2. 数据库连接失败
错误：`Communications link failure`

检查：
- MySQL 服务是否启动
- 数据库 `bickdemo` 是否已创建
- 用户名密码是否正确

### 3. 找不到 Java
错误：`'java' 不是内部或外部命令`

解决：设置 JAVA_HOME 环境变量或把 Java 添加到 PATH

### 4. 权限错误（Windows）
右键 IDEA -> 以管理员身份运行
